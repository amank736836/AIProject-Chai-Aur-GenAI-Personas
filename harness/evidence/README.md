# Evidence

Raw artefacts produced by real executions (never generated by hand, never edited after the fact). Every test
case that was executed links to a file here; unexecuted cases link to nothing.

```
evidence/
├── api-responses/   raw HTTP responses, headers and reproducer output (31 files, RUN-2026-001)
├── logs/            lint/typecheck/build/dev-server logs, npm audit output, PR history, run context
├── performance/     latency measurements (JSON + markdown)
├── screenshots/     README explaining why it is empty (no browser runtime — KI-005)
├── videos/          N/A here — no browser/recording runtime; planned with the manual UI pass (KI-005)
└── database-results/ N/A — the project has no database (../test-scenarios/database.md covers the decision)
```

## How evidence is produced

| Artefact | Producer |
|---|---|
| `api-responses/TC-*.json|txt` | the automated suites (`harness/automation/**/*.test.mjs` write evidence through `writeEvidence()`) |
| `api-responses/repro-findings.txt` | `node harness/automation/utilities/repro-findings.mjs` (bug reproducer, no credentials needed) |
| `logs/lint.log`, `logs/typecheck.log`, `logs/api-tests.log`, … | `harness/automation/scripts/run-all.sh` → `harness/test-results/latest/raw/` (copies are referenced, not duplicated) |
| `logs/build.log` | `npm run build` (fails offline — KI-003) |
| `logs/npm-audit.json`, `logs/npm-audit-summary.txt` | `npm audit --json` / `npm audit` / `npm audit --omit=dev` |
| `logs/pr-history.txt` | `gh pr list --state all` |
| `performance/performance-latency.{json,md}` | `node harness/automation/performance/api-latency.mjs` |
| `screenshots/*` | manual capture during a UI session (none yet) |

## Rules

1. **Never fabricate evidence.** A missing artefact is reported as `NOT_EXECUTED` in the case, not filled in.
2. Evidence is immutable once a run is closed; a new run writes new files (or a new `RUN-*` folder in
   `../test-results/`).
3. Evidence must contain no secrets: provider keys never appear in payloads (verified by TC-069); the
   failure text of TC-005 mentions *names* of environment variables, not their values.
4. Keep files small and text-based; the largest artefact here is the SSR HTML snapshot (~22 KB).
5. Link evidence from the test case that produced it (`Evidence:` field) so a reader can replay the run.
