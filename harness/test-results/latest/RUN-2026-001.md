## Why pass = 35 while the harness reports 18 bugs

The suites are intentionally written to **stay green while a defect is open**: the affected assertion is tagged
`{ todo: "BUG-xxx" }`, so it runs, reports `# TODO`, and does not fail the run. This keeps the suite useful as a
regression gate (exit 0 = “no *new* breakage”) without hiding known gaps. Read this record together with
[`../../TESTING_STATUS.md`](../../TESTING_STATUS.md) and
[`../../bugs/README.md`](../../bugs/README.md) — never as a green build alone.
