# BUG-018 — Primary avatar upstream (`source.unsplash.com`) was retired

| Field | Value |
|---|---|
| **Bug ID** | BUG-018 |
| **Title** | Primary avatar upstream (`source.unsplash.com`) was retired |
| **Severity** | Low |
| **Priority** | P3 |
| **Feature** | FEAT-005 |
| **Environment** | commit `d24eb41`, dev server, RUN-2026-001 (offline environment). External confirmation: Unsplash deprecated the Source service in 2021 and shut it down in 2024 |
| **Preconditions** | none |
| **Steps to Reproduce** | 1. `curl -X POST http://localhost:3000/api/fetch-image -H 'Content-Type: application/json' -d '{"name":"Hitesh"}'` 2. Observe that the response always points at `ui-avatars.com` 3. Read `src/app/api/fetch-image/route.ts:7-15` (primary URL) |
| **Expected** | Either a real photo URL is returned for the primary branch, or the dead branch is removed |
| **Actual** | The HEAD probe of `https://source.unsplash.com/128x128/?face,portrait,person,…` fails/redirects, so every custom persona gets a generated initials avatar. The dead code also costs one failed outbound request per persona creation |
| **Reproducible** | YES (deterministic in this environment; on any host the retired service returns 302/404) |
| **Evidence** | [`../../evidence/api-responses/TC-023-fetch-image-ok.json`](../../evidence/api-responses/TC-023-fetch-image-ok.json), [`TC-026-fetch-image-fallback.txt`](../../evidence/api-responses/TC-026-fetch-image-fallback.txt) |
| **Root Cause** | Upstream service retirement; no replacement source and no test would have caught it (the fallback silently succeeds) |
| **Fix** | Remove the dead primary branch and keep `ui-avatars` (or add a stable alternative such as a real Unsplash API key, DiceBear, or a locally bundled default) — and note the choice in the README's feature list |
| **Regression Test** | TC-026 (automated, currently `{ todo: "BUG-018" }`), TC-025 (blocked offline) |
| **Status** | OPEN |
