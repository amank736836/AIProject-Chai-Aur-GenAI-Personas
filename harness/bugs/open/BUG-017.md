# BUG-017 — Critical/high advisories in production dependencies (`next@15.4.10`)

| Field | Value |
|---|---|
| **Bug ID** | BUG-017 |
| **Title** | Critical/high advisories in production dependencies (`next@15.4.10`) |
| **Severity** | Critical |
| **Priority** | P0 |
| **Feature** | platform / release |
| **Environment** | commit `d24eb41`, `npm audit` with the current registry data (2026-10-07), Node v22.22.3, npm 10.9.8 |
| **Preconditions** | none |
| **Steps to Reproduce** | 1. `npm audit --omit=dev` 2. `npm audit` 3. `npm ls next` |
| **Expected** | No critical/high advisories in dependencies that ship to production |
| **Actual** | Production surface: **10 advisories** (1 critical, 4 high, 5 low). Whole tree: **28 advisories** (2 critical, 19 high, 2 moderate, 5 low). Directly affected production packages: `next@15.4.10` (critical + high: RCE on Windows-hosted servers GHSA-p293-qw3h-jr36, RCE in the Image Optimization API GHSA-2xp9-vwfh-vxw4, plus multiple DoS/middleware-bypass advisories), `sharp@0.34.3`, `postcss@8.4.31`, `nanoid`, `source-map-js`. `npm audit fix` proposes `next@15.5.27` (non-breaking) |
| **Reproducible** | YES |
| **Evidence** | [`../../evidence/logs/npm-audit.json`](../../evidence/logs/npm-audit.json), [`../../evidence/logs/npm-audit-summary.txt`](../../evidence/logs/npm-audit-summary.txt) |
| **Root Cause** | Dependencies drift out of date; the repository has no dependency-update automation beyond two one-off Dependabot PRs (#1 open, #2 merged) |
| **Fix** | Upgrade `next` to `>=15.5.27` (semver-compatible with the declared `^15.4.10`) and re-run the build + full harness. Mitigating context to record in the fix PR: the app does not use `next/image` (uses `<img>`) and deploys on Linux, which reduces (but does not remove) exposure to the image-optimizer and Windows RCE advisories; the DoS/middleware advisories apply to any App Router deployment |
| **Regression Test** | TC-072 (automated invocation, baseline recorded in the case) |
| **Status** | OPEN |
