# BUG-002 — Saved chat is never restored: writer and loader use different formats

| Field | Value |
|---|---|
| Bug ID | BUG-002 |
| Title | Saved chat is never restored: writer and loader use different formats |
| Severity | High |
| Priority | P0 |
| Feature | FEAT-006 (chat history persistence) |
| Environment | commit `d24eb41`, Node v22.22.3 unit harness (RUN-2026-001); same in a browser |
| Preconditions | One message exchanged, then reload |
| Steps to Reproduce | 1. `node harness/automation/utilities/repro-findings.mjs` (BUG-002 line) 2. Or in a browser: send a message, reload, observe the empty transcript 3. Or in code: `saveChatToCookie(chat)` followed by `loadChatFromCookie()` |
| Expected | `loadChatFromCookie()` returns the exact array that was saved (`deepEqual`) and a reload shows the transcript |
| Actual | `saveChatToCookieWithData()` writes `btoa(JSON.stringify(chat))`, while `loadChatFromCookie()` expects a payload in the shape `hash|base64` and applies a transform — so it either returns `null` or a mangled structure. The round trip never holds: transcript is lost on every reload |
| Reproducible | YES (deterministic, unit-level) |
| Evidence | [`../../test-results/latest/raw/unit-tests.log`](../../test-results/latest/raw/unit-tests.log) (TC-056 fails as `# TODO`), [`../../evidence/api-responses/repro-findings.txt`](../../evidence/api-responses/repro-findings.txt) |
| Root Cause | Two independent format decisions in `CookieManager.ts` — `saveChatToCookieWithData()` (line ~44, plain `btoa(JSON)`) vs `loadChatFromCookie()` (line ~50, splits on `\|` and hashes). The dead hash branch (`hashData()`, line 15) was never wired up, and `page.tsx:163` never calls the loader at all (`loadChatFromCookie` imported but unused) |
| Fix | Pick one format (plain `encodeURIComponent(JSON.stringify(chat))` is the simplest, Unicode-safe choice — see BUG-003) and use it in both directions; delete or implement `hashData()`; call the loader on mount so the transcript actually renders |
| Regression Test | TC-056 (automated, `{ todo: "BUG-002" }`), TC-058 (locks the current loader behaviour so the fix must update it) |
| Status | OPEN |
