# BUG-015 — Cookie name is built from unsanitised input (`;` becomes an attribute)

| Field | Value |
|---|---|
| **Bug ID** | BUG-015 |
| **Title** | Cookie name is built from unsanitised input (`;` becomes an attribute) |
| **Severity** | Medium |
| **Priority** | P2 |
| **Feature** | FEAT-004 |
| **Environment** | commit `d24eb41`, dev server, RUN-2026-001 |
| **Preconditions** | none (anonymous endpoint) |
| **Steps to Reproduce** | 1. `curl -s -X POST http://localhost:3000/api/create-persona -H 'Content-Type: application/json' -d '{"name":"x; Path=/evil"}' -D - -o /dev/null \| grep -i set-cookie` 2. Inspect the header |
| **Expected** | A cookie name that cannot contain delimiters: `personaData-x-path-evil` or a rejected name (400) |
| **Actual** | `set-cookie: personaData-x;-path=/evil=%7B…%7D; Path=/; HttpOnly; SameSite=Lax; Max-Age=2592000` — the `;` inside the name terminates it early and `-path=/evil=…` becomes a malformed attribute. Browsers discard the malformed cookie, so the persona silently fails to persist |
| **Reproducible** | YES |
| **Evidence** | [`../../evidence/api-responses/TC-019-create-persona-cookie-injection.txt`](../../evidence/api-responses/TC-019-create-persona-cookie-injection.txt) |
| **Root Cause** | `src/app/api/create-persona/route.ts:41` — `personaData-${name.toLowerCase().replace(/\s+/g,"-")}` sanitises whitespace only; `;`, `=`, `,`, control characters and non-ASCII survive into the header. The same construction exists in `chat/route.ts:150-156` for `chatHistory-*` |
| **Fix** | Slugify strictly (`name.toLowerCase().replace(/[^a-z0-9@._-]+/g,"-").slice(0,64)`) before building any cookie name, and reuse one helper in both routes |
| **Regression Test** | TC-019 (automated, `{ todo: "BUG-015" }`) |
| **Status** | OPEN |
