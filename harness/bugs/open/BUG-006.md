# BUG-006 — Custom persona tone (string) is ignored by the prompt builder

| Field | Value |
|---|---|
| **Bug ID** | BUG-006 |
| **Title** | Custom persona tone (string) is ignored by the prompt builder |
| **Severity** | High |
| **Priority** | P0 |
| **Feature** | FEAT-004 (custom persona), FEAT-010 (prompt building) |
| **Environment** | commit `d24eb41`, Node v22.22.3 (unit reproduction of the real data shapes), RUN-2026-001 |
| **Preconditions** | A persona created through `/api/create-persona` (cookie `personaData-<slug>` where `tone` is an LLM text string) |
| **Steps to Reproduce** | 1. `node harness/automation/utilities/repro-findings.mjs` (BUG-006 line) 2. Or: `POST /api/create-persona {"name":"Test Persona"}` with a working provider key, copy the `personaData-test-persona` cookie, then call `buildPrompt("test-persona","hello","Test Persona",[],cookies)` 3. Inspect the prompt |
| **Expected** | The generated tone description shapes the persona (system prompt or tone guidelines) |
| **Actual** | The prompt is the generic template with **empty** guidelines: `You are acting as Test Persona.\n Tone guidelines:\n \n...` — the tone text is silently dropped (`tone text present in prompt: false`) |
| **Reproducible** | YES (deterministic) |
| **Evidence** | [`../../evidence/api-responses/TC-032-prompt-custom-tone.txt`](../../evidence/api-responses/TC-032-prompt-custom-tone.txt), `../test-results/latest/raw/unit-tests.log` (TC-032) |
| **Root Cause** | Data-shape mismatch: `create-persona/route.ts` stores `tone` as a **string**, while `prompt.js` only honours `tone` when it is an **object** with `systemPrompt`/`styleNotes` (`getCookiePersonaTone()` returns it, but the object branch never matches, so `systemPrompt` stays `null`) |
| **Fix** | Normalise both sides: e.g. store `tone: { systemPrompt: <text> }`, or teach `prompt.js` to accept a string tone (`systemPrompt = typeof tone === "string" ? tone : tone.systemPrompt`) |
| **Regression Test** | TC-032 (automated, `{ todo: "BUG-006" }`), TC-012 (integration, PLANNED) |
| **Status** | OPEN |
